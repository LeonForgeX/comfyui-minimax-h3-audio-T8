# H3 → LTX 标准潜空间（EXP）

本分类先提供转换并保存标准 LTX LATENT 的模板，不是完整 LTX 精修或视频生成模板。
选自己的 H3 `.latent`，填写固定版本 adapter 源码和模型目录，确认实际帧数、24fps 与时间策略。
默认 CPU/F32；CUDA/BF16 是明确选项，不保证整条 LTX 精修链能在16GB显卡上运行。

已有 H3 联合音视频 LATENT 可直接接到转换节点。原始 H3 AV 从第2输出原样返回，
仅第1输出为 LTX 视频 LATENT；音频不转换，也不自动额外放大或拉伸画面。
73帧可选 exact；124帧需明确选 pad129 / crop121，并在下游相应处理原音时长。

已完成固定真实73帧转换、原生VAE解码、公开精修链完整成片及原生工作流保存/API检查；

保留342个旧节点顺序，只追加本节点为第343个；不冒称全仓或全部输入效果通过。
模板 JSON 的 development_exp_human_pending 是原创建时的历史元数据；
为保留原接线／参数字节不迁移模板，最新验收以 [源码交付说明](../../../docs/H16_SOURCE_UPDATE_20260917.md) 为准。
