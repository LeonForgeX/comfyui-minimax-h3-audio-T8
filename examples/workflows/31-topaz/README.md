# 正式 Topaz 高清后处理（可选）

先用 Environment 图填写正式程序、模型定义与模型数据目录；该图只检查签名和接口，不跑增强。
Video 图接原生视频文件与环境输出。默认2x需自行在正式 Topaz 准备对应权重。
本机已通过正式授权引擎准备下拉框内14个高清模型和5个插帧模型，并逐个完成短片生产worker机械验证；商业权重不随仓库发布。已有指定人物、游戏和长片样例获画音认可，不代表所有模型和素材。

`1x`是原尺寸增强；`2x/4x`是宽高倍率，不是插帧。默认`parameters_json={}`使用程序默认。
高级`size_mode=target_dimensions`按指定宽高输出并忽略倍率：先Topaz增强，再调整
增强结果到目标尺寸。须保持原比例、1至4倍、偶数32至8192。默认scale及旧工作流不变。
1.5x短片已通过1536×768/72帧与原音频检查，并获对应画音认可，不代表任意尺寸/模型均验收。
默认8-bit SDR直接输出H.264；10-bit SDR须显式选择`delivery_hevc_main10`。HDR仍不支持。无损MOV/MKV母版只供审计；逐包及解码PCM均核对。节点已经保存成片，不要再接SaveVideo；不覆盖原片，不自动下载。
导入Video图后把示例`source.mkv`替换为自己的视频。不要使用裁切/未保存的帧批次输入。

`Upscale_Then_Interpolation`图按顺序先高清、再插帧。最终成片取第二个节点输出，两阶段严格串行。单卡GPU序号保持0，多卡可在高级项选择。
