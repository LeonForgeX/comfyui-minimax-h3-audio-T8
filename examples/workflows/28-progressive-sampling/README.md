# H3 渐进首采工作流

把本目录的 JSON 拖入你平时使用的 ComfyUI 即可打开。不是 API 格式，不需要经过浏览器“导出”才能使用。

- T2VA：文字生成音视频。
- I2VA：用一张首帧图生成音视频，先在“首帧参考图”节点中选择你的图片。

两份图都是小画幅采 6 步、学习型潜空间放大后再采 2 步，总共 8 步。不是 VDN 的 8+4 二采，也不是成片超分。

除原有 H3 模型、新版 Turbo EMA B、文本模型和音视频 VAE，还需已有的学习型放大模型：

`ComfyUI/models/latent_upscale_models/minimax_h3_latent_upscaler_3d_fp16.safetensors`

不需要安装 SelfLift 插件或重新转换模型。完整参数说明见 [渐进首采说明](../../../docs/PROGRESSIVE_SAMPLING_EXP.md)。

随 1.77.0 以 EXP 工作流提供：两份图已实际在界面加载并保存，后台 Core API 参数和连线验证通过；完整浏览器 API 导出往返尚未完成。T2VA/I2VA 已审画面相近、可接受，I2VA 环境声及人物对白组声音和口型正常；游戏组仍有音量和音效差异，声音不是逐样本保留。已测试 1024×512、约 3 秒；32 秒路线未通过，不能据此承诺其他画幅、长片或普遍加速。
