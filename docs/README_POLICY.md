# README 首页维护规则

首页是安装和选工作流的入口，不是开发日报或全部验证记录。中英文同步维护。

1. 首页只保留产品简介、唯一当前版本、安装、工作流入口、模型、重要限制和社媒。每页不超过 140 行、10KB、8 个标题。
2. 新版本内容写入根目录 `CHANGELOG.md`，详情写 `docs/RELEASE_版本.md`；首页只更新当前版本标记，不追加日期段落、发布历史折叠框、内部收据或长参数清单。
3. 详细参数、目录树和第三方程序要求写专题文档或 `README_DETAILS_ZH/EN.md`。旧首页信息已完整迁移：历史段落归档，说明文档继续可点击访问。
4. 模型入口保留 Taeh3-Comfy 与 Meridian-Comfy；明确时序／2D 的区别及 Meridian／Omega 的不同格式和许可。不要把 Omega 称作 INT8。
5. 保留用户提供的社媒和邀请链接，不冒充上游官方认可。不要把旧历史状态当成最新验收状态。
6. 编辑后执行 `python tools/check_readme_homepage.py` 及 `python tools/prepare_release_version.py --check`。CI 同样检查长度、结构、版本一致性、必要链接和本地链接存在性；错误必须修复，不能删除检查绕过。
7. README 引用的新文档需要进入 Registry 发布文件白名单。检查归档包时使用官方 Comfy CLI 行为，不按自己的忽略规则假装打包成功。
8. 只改下载提示、README 或包内文档且版本未变时，GitHub 源码更新不重复提交同一 Registry 版本。真正版本变更及手动 dispatch 仍执行上传与激活门禁；跳过同版本上传不等于 Registry 已激活。

本次只改文档和节点下载提示，没有迁移旧图、重设采样默认值或替换模型。
