# 帧数与时长：不再设置人为硬上限

2026-09-17 起，本项目移除了视频总帧数、输出时长及时间线位置的人为上限。超过官方建议的参考视频长度仅记录警告，不再因为超过360帧拒绝执行；869帧参考视频已覆盖三条条件路径的回归。

保留模型必须的帧对齐与最短长度、真实素材越界检查、模型/后端兼容性以及上下文容量。分块大小、最大单场景时长、修复窗口等由用户明确选择的设置仍然生效，但输入框不再限制用户提高这些值。默认值不变，未改采样、音频、接缝、颜色匹配或放大算法。

这不代表任意长度都能在当前显存运行，也不保证超出训练范围的质量。参考视频仍按原有目标帧数裁切与对齐逻辑处理，没有承诺整个参考素材全部参与生成。语音参考音频的边界策略不属于视频帧数限制，本次未改。

部署至正式核心目录后，需要重启ComfyUI加载新的Python和节点输入范围；本次没有自动重启用户服务或改写旧工作流。

验证：开发树受影响范围980项CPU测试通过、1项条件跳过；实际正式核心371项CPU测试通过、339个唯一节点ID。没有为超长输入重跑GPU或推送发布。先前FastH3V2发行候选包早于本次修改，不能用于证明当前源码已打包验证。
