# 曜石导演台工作台

从 ComfyUI 左侧栏“导演台”进入。左侧选择镜头，中间编辑提示词和镜头设置，右侧管理素材、查看输入或播放成片；底部可生成当前镜头或按顺序生成全部镜头。原技术检查、导出和项目操作仍可从工具菜单访问。

## 模型与采样

顶部“模型与采样”中，底模、文本编码器和视频／音频 VAE 共用一组选择。旧项目默认保持单采；选择“双采样”后，一采与二采各自有独立的有序多 LoRA 列表，可设置文件、强度、启用状态和顺序。复制列表不会把后续修改绑定在一起。全片默认只影响跟随全片的镜头；切换本镜独立设置后不再随全片变化。点击应用才提交窗口修改，取消保留原配置。

目标分辨率按 MP 总像素选择，预检回显实际 LOW/HIGH 尺寸；按 H3 网格及学习型放大器规则对齐，不保证恰好等于输入的像素总数。双采使用一个底模分出两阶段 LoRA 链，先低分辨率采样，再学习型 3D latent 放大和高分辨率细化。标准双采与 FastH3 V2 独立路线互斥；缺文件和真实尺寸错误仍会明确报错。

LoRA 已配置、视频已生成不等于所有 patch 都成功生效。部分裁剪底模与 LoRA 组合可能在 Core 日志中报告形状不匹配；保留用户选择并提示风险，应检查实际 patch 日志。任意 LoRA 组合、人物一致性、声音、口型及连续长片质量都需要单独验收。

## 提示词、素材与成片

- 新手模式整段粘贴本镜提示词；高级模式分整镜描述和时间事件。两种草稿分别保留，仅当前模式参与编译。
- 全片设定和共享素材跨镜头复用；图片、视频、音频统一从素材区加入，再分配用途或在光标处插入对应引用。
- 放大提示词编辑不会被后台任务完成或失败消息覆盖；关闭编辑后仍可打开任务状态查看详情。
- 生成成片与输入素材分开显示。已有结果通过持久媒体回执恢复；失败不会删除此前成片，也不会自动重采样。没有结果的镜头不会显示伪造成片。

## 保存、切换与网络恢复

项目保存与本地草稿分开：保存请求期间的新编辑保留为草稿，不冒称已经上传。并发版本冲突不会自动覆盖服务端。另存成功才切换项目身份。

连续打开项目只接受最后一次有效请求；载入期间出现新编辑时保留当前草稿，提示重新载入。普通上传和素材重连均固定原项目身份，切项目后不会把迟到的上传结果绑定到新项目。取消任务只影响原任务的状态跟踪。

全部生成在提交前冻结项目快照并按顺序执行。每次生成使用请求 ID，响应不明时重试相同请求而不是直接重复排队；刷新恢复已有任务只查询状态。这不等于跨 Core 重启的 latent 阶段续算。

## FFmpeg 与更新

更新 GitHub 源码后重启 ComfyUI，并刷新导演台以加载新增后端和前端模块。本次源码更新不改变版本号，也不表示 Registry 已重新发布。

生成前检查已安装的 FFmpeg：支持 `T8_FFMPEG_PATH` 指向可执行文件；随后检查 PATH、整合包的 `ffmpeg/bin` 和已安装的 imageio-ffmpeg。不会自动下载程序，显式配置无效时会报错而非悄悄换程序。

自动化状态测试使用真实前端模块与隔离网络替身；CPU 图编译、无头浏览器交互和实际 GPU 成片是不同层级的验证，不能相互替代。
