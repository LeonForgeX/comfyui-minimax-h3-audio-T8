## 预处理与时间坐标

可选预处理参考固定ReShot源版本`2e2279aad2878a87d3374f2e91533b38ebe18050`、reshot0.4.0、Video-Depth-Anything Small修订`256875362cff76724b920335dfb4b29dd611f66e`。来源分别为maosika-ai/ComfyUI-ReShot和depth-anything/Video-Depth-Anything-Small；代码/Small模型许可为Apache2，不推广其他规格许可。不是默认依赖，当前仅研究目录隔离安装，未装入用户Comfy环境。

两路先统一CFR24、同一起点、同一空间裁剪。模板736×416，不能只裁深度不裁源。保留整片浮点深度，用同一min/max范围一次归一化后再切片；逐帧或逐段独立拉伸会引入尺度变化。上游VDA已有内部时序窗口，不另外重启模型按H3段各自推理。上游Comfy封装缓存模型不能视为自动卸载，所以当前使用独立文件阶段。

当前8秒预处理：同一RGB源前192帧，VDA Small九个内部窗口；原始float192×364×644映射回736×416。全片统一灰度范围，24fps/192帧/8秒，无音轨，全解码机械检查通过。原始深度留存，H264 CRF12仅作有损传输。不要使用CRF0：该上游封装固定High profile，与无损编码不兼容。已经生成的float可直接重新封装，无需再次GPU推理。

## 长度、人物与声音

Ref2VA图沿用124帧渲染窗口/context22。第一段取源0–123，第二段参考从102开始，含22帧重叠；交付截止192，只有隐藏采样尾巴可保持源末帧。用户实际交付范围不足素材会报错，不循环重复片头。深度图也是软参考，不能保证严格姿态或完全去除源人物。

Fun图Conditioning与Apply都必须是736×416×124，17n+5帧网格。当前Apply会截断过长输入、复制末帧补短：必须准备至少124个真实控制帧，不把补齐当动作成功。生成后丢弃最后4帧，与原RGB音乐一起裁到精确5秒。不能把192帧控制直接套在每个124帧内循环上。Fun的8维pruned/basis只能与主模型实际8维配对，dense2688只能配2688；以实际权重为准，未知不代表已兼容。

当前Fun模板明确使用`minimax_h3_ref2va_pruned_int8_convrot.safetensors`＋`minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors`，本地文件头实查8/8。初版误继承RGB模板的dense Ref2VA，实际2688/8，被运行期检查在采样前拦截；已修正选模，并补文件头预检，原运行期保护没有放宽。API接线检查不能代替实际权重结构检查。

原RGB音乐连接最终交付而非驱动模型重唱，深度视频无声；音乐必须覆盖目标时间段。两图默认起点0，换起点请先把两路导出到同一片段，避免只改一侧。最终AAC有损，不宣称PCM逐样本不变或口型已证明。Fun无Video1引用，仅以Picture1描述目标人物。
